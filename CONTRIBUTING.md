# Contributing to Awesome AI Security Tools

Thank you for your interest in improving this list.

### Strict Inclusion Criteria
- Clear focus on AI security or high-value AI-assisted cybersecurity
- Active maintenance preferred (recent commits)
- Usable license (permissive strongly preferred)
- Demonstrable practical value
- Reasonable popularity or unique technical contribution
- Must not lower the overall signal-to-noise ratio

### How to Contribute
1. Fork the repository
2. Add your entry in the correct section using the existing format
3. Open a Pull Request with a short justification
4. Low-quality, abandoned, purely promotional, or off-topic entries will be rejected

### Entry Format
- [Name](link) 🟢/🔬/🟠/⚠️ – One-sentence description

### Ethical Note
All tools should be framed for authorized testing only. Do not submit tools whose primary purpose is unrestricted malicious use.
